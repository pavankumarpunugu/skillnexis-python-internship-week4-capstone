# SkillNexis Week 4 - Employee Data Analysis

## Capstone Project

This project analyzes employee data using Python and Pandas.

### Features

- Load employee records from a CSV file
- Calculate average salary
- Count employees by department
- Filter employees above a salary threshold
- Export filtered employees to a new CSV file
- Interactive command-line menu

## Technologies

- Python
- Pandas
- CSV / File Handling

## Project Files

- `employee_data_analysis.py` - Main Python application
- `employee_dataset.csv` - Input employee dataset
- `requirements.txt` - Python dependency
- `employees_above_salary_threshold.csv` - Generated output file

## How to Run

### 1. Install Pandas

```bash
pip install -r requirements.txt
```

### 2. Run the project

```bash
python employee_data_analysis.py
```

The program will automatically create a sample CSV dataset if the input file is missing.
